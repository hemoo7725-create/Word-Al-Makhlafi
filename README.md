# Word Al-Makhlafi — Android

تطبيق Android لتحويل PDF والصور والمستندات إلى ملف Word قابل للتحرير.

- مجاني بالكامل من داخل التطبيق: بدون اشتراك أو دفع شهري أو حد استخدام مضاف من التطبيق.
- يدعم PDF والصور، مع OCR عربي + إنجليزي.
- يدعم DOCX/XLSX/PPTX لاستخراج النص.
- يسمح باختيار عدة ملفات ثم إنشاء ملف DOCX واحد.
- GitHub Actions يبني APK تلقائيًا، وينزّل نماذج OCR أثناء البناء.

> هذه نسخة أولية عملية وليست بعدُ نسخة متجر نهائية؛ قد تحتاج مراحل لاحقة لتحسين تنسيق الجداول، الصور، والتخطيط الأصلي للمستندات.
